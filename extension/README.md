# PromptPilot AI Chrome extension (unpacked)

Not published on the Chrome Web Store. To install:
1. Download https://promptpilot-ai-psi.vercel.app/promptpilot-extension.zip and unzip it.
2. Open chrome://extensions, turn on Developer mode, click "Load unpacked" and pick the unzipped folder.
3. Select a prompt on any page (ChatGPT, Claude, Gemini…), click the extension icon, then "Improve".
